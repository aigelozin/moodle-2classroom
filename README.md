# Moodle → Google Classroom

Переносит курсы из резервных копий Moodle (.mbz) в Google Classroom на личный Gmail.

| Moodle | Google Classroom |
|---|---|
| Курс (название, краткое имя, описание) | Курс (ACTIVE, владелец — вы) |
| Раздел | Тема (порядок как в Moodle). Если раздел назван по умолчанию («Topic 5»), название берётся из первой строки метки в начале раздела |
| Описание раздела | Материал «О разделе: …» |
| Страница, книга | Google Doc (картинки встроены) + видео/аудио и ссылки из текста. Встроенные плееры (`<video>`, `<audio>`, iframe) в Docs не работают, поэтому в документе они заменяются ссылками «▶ Видео», а YouTube прикрепляется к материалу как видео |
| Файл, папка | Файлы в Google Drive, прикреплены к материалу |
| URL | Ссылка или YouTube-видео |
| Пояснение (label) | Материал с текстом, картинки — файлами |
| Тест | Google Form в режиме теста с баллами и ответами → задание со ссылкой |
| Скрытое в Moodle | Черновик (или `--skip-hidden`) |

Не переносятся: форумы, задания (assign), семинары, wiki, H5P/SCORM, студенты, оценки.
Всё пропущенное перечислено в отчёте `out/reports/<курс>.md`.

**Вопросы теста:** одиночный/множественный выбор, верно/неверно, короткий ответ, числовой
(точное совпадение), эссе (ручная проверка), на соответствие (выпадающий список на каждую пару),
описание. Если в Moodle каждый вопрос был на отдельной странице, форма делается одностраничной. Случайные вопросы (random), картинки в вопросах, частичные баллы и штрафы
не поддерживаются Forms — это попадает в «Предупреждения».

Подробная инструкция для сервера с нуля: [install2server.md](install2server.md).

## 1. Google Cloud (один раз, ~10 минут)

1. https://console.cloud.google.com → создать проект.
2. «APIs & Services → Library» → включить **Google Classroom API**, **Google Drive API**, **Google Forms API**.
3. «OAuth consent screen» → External → заполнить название и email → в **Test users** добавить свой Gmail.
4. «Credentials → Create credentials → OAuth client ID» → тип **Desktop app** → скачать JSON
   и положить рядом со скриптом как `credentials.json`.

## 2. Установка на сервере

```bash
cd moodle2classroom
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

## 3. Проверка без Google

```bash
python migrate.py plan /path/to/backups/*.mbz
```

Смотрите `out/reports/*.md`: что станет темами, материалами, тестами, что пропущено.

## 4. Вход в Google (один раз)

Проще всего на сервере без браузера:

```bash
python migrate.py auth --manual
```

Откройте показанную ссылку на любом устройстве, войдите и разрешите доступ. Браузер затем
покажет ошибку «localhost не отвечает» — это нормально: скопируйте адрес из адресной строки
и вставьте его в терминал.

Другой вариант — пробросить порт со своего компьютера:

```bash
ssh -L 8765:localhost:8765 user@server
python migrate.py auth
```

Откройте показанную ссылку в браузере на своём компьютере, войдите тем Gmail, который будет
владельцем курсов. Токен сохранится в `token.json` (права 600, не публикуйте его).

## 5. Перенос

```bash
python migrate.py run /path/to/backups/*.mbz
```

Ход переноса записывается в `out/state/`. Если что-то оборвалось (лимиты API, сеть),
просто запустите ту же команду ещё раз: уже созданное не будет создано повторно.
Чтобы перенести курс заново с нуля, удалите его state-файл.

Файлы ложатся в Google Drive в папку `Moodle → Classroom/<курс>`.

Ссылки на все перенесённые курсы (Classroom и папка в Drive) собираются в `out/courses.md` —
файл обновляется после каждого `run`. Показать его: `python migrate.py list`.

Тесты публикуются и открываются по ссылке всем (`--private-forms` — не открывать).
API Classroom не умеет прикреплять форму как «тест» (только ссылкой), поэтому импорт оценок
сам не включится. Если он нужен: откройте задание → удалите ссылку → «Добавить → Google Диск» →
выберите эту же форму → включите «Импорт оценок». Иначе результаты видны в самой форме.
